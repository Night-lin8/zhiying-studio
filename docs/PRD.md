# 需求文档：AI 品牌宣传视频智能体

状态：已确认
日期：2026-09-19
提出人：毕业设计项目组

## 1. 背景与问题

中小品牌、校园创业团队和个人创作者需要快速制作短视频宣传素材，但完整视频制作通常涉及文案、分镜、抠像、字幕、配音和剪辑等多个环节。使用多个分散工具会消耗大量时间，在线服务还存在素材隐私和费用问题。

本项目需要一个离线优先、在线可选的品牌宣传视频智能体，让用户通过少量品牌信息即可获得可用的宣传脚本和成片预览，并能在本地完成背景替换与视频导出。

## 2. 目标用户与场景

| 角色 | 场景 | 当前痛点 |
| --- | --- | --- |
| 校园创业者 | 为新店、社团活动制作宣传视频 | 没有专业剪辑能力，制作周期长 |
| 电商运营人员 | 批量制作产品展示素材 | 文案和视觉工具割裂，返工频繁 |
| 个人内容创作者 | 制作有品牌感的短视频 | 在线服务成本高，素材上传有隐私顾虑 |
| 毕业设计答辩评审 | 考察 AI 应用完整性、创新性和可演示性 | 需要可运行、可验证、可讲解的系统 |

## 3. 目标与非目标

业务目标：

- 用户输入品牌名称、产品、人群和卖点后，可在 1 分钟内获得标题、文案和分镜
- 用户上传主体图片后，可在本地完成背景替换
- 用户可以预览 16:9、9:16、1:1 成片效果并导出视频和字幕
- 系统在无网络、无付费 API 时仍可完整运行
- 项目具备可演示、可测试和可答辩的完整性

非目标：

- 不提供商业级自动人物建模与三维场景生成
- 不替代专业剪辑软件的全部功能
- 不在离线模式中依赖任何云端大模型
- 不上传或修改用户原始素材文件

## 4. 用户故事

作为校园创业者，我希望输入产品信息后立即获得宣传文案和分镜，以便快速开始视频制作。

作为电商运营人员，我希望替换产品照片背景并保持主体边缘清晰，以便统一店铺视觉风格。

作为内容创作者，我希望在断网时仍能生成脚本和预览视频，以便在素材敏感或网络受限的环境中工作。

作为答辩学生，我希望导出脚本、字幕、透明图与成片视频，以便完整展示系统运行结果。

## 5. 操作流程

1. 用户打开应用，进入“创意输入”。
2. 用户填写品牌名称、产品名称、行业、描述、目标人群、核心卖点、表达风格和成片比例。
3. 用户点击“生成内容”，系统展示标题、卖点、口播文案与 6 个分镜。
4. 用户可更换创意方向并重新生成，或复制、导出 Markdown 脚本。
5. 用户进入“背景替换”，上传主体图片。
6. 用户选择背景色取样、绿幕、蓝幕或浅色背景抠像，调整容差和边缘柔化。
7. 用户从背景库选择背景或上传自定义背景。
8. 用户将合成结果应用到分镜，进入“预览导出”。
9. 用户试听本地配音，切换字幕和自动切镜，播放或录制成片。
10. 用户导出 SRT 字幕、透明 PNG、Markdown 文档和 WebM 视频。

主要分支：

- 未配置在线服务：系统始终使用离线规则引擎。
- 在线服务已配置但请求失败：系统自动回退到离线引擎。
- 上传素材为空或格式不受支持：系统提示用户重新选择。
- 浏览器不支持视频录制：系统提示更换新版 Edge 或 Chrome。

## 6. 验收标准

- 无网络环境下可完成脚本生成、抠像、预览和文件导出
- 离线生成结果包含标题、卖点、口播文案和不少于 6 个分镜
- 四种抠像方式均可在浏览器内完成
- 三种画幅比例均可预览
- 导出文件可被浏览器下载并打开
- 在线服务为可选能力，不配置时不影响核心功能
- 项目运行过程不修改用户上传的原始文件
