# 演示脚本：AI 品牌宣传视频智能体

## 演示主题

以“星澜咖啡：山野冷萃拿铁”为例，展示从创意输入到成片导出的完整流程。

## 第一部分：需求与系统定位

口播：本项目面向品牌宣传视频制作场景，重点解决文案、分镜、抠像、字幕和成片制作流程分散的问题。系统采用离线优先设计，未配置在线服务时也能完整运行。

画面：打开应用首页，展示顶部“离线模式”状态和四个制作步骤。

## 第二部分：离线文案与分镜生成

口播：用户只需要填写品牌、产品、行业、目标人群和核心卖点。系统通过离线规则引擎生成标题、宣传语、卖点、口播文案和六个分镜。

操作：

1. 保持默认示例信息。
2. 点击“生成内容”。
3. 展示生成的标题和口播文案。
4. 点击右侧分镜卡片，展示镜头、字幕和时长。
5. 点击“导出文档”，说明可导出 Markdown 脚本。

## 第三部分：主体抠像与背景替换

口播：背景替换模块在浏览器本地处理图片，不上传原始素材。系统支持背景色取样、绿幕、蓝幕和浅色背景。

操作：

1. 进入“背景替换”。
2. 上传 `assets/samples/sample-product.png`。
3. 展示自动抠像结果。
4. 点击画面背景进行颜色取样。
5. 调整容差和边缘柔化。
6. 分别选择“纯净空间”“科技蓝调”“自然生机”背景。
7. 点击“应用到分镜”。

## 第四部分：成片预览与导出

口播：预览模块支持横屏、竖屏和方形画幅，可试听系统本地配音，并导出标准字幕和 WebM 成片。

操作：

1. 进入“预览导出”。
2. 选择 9:16 竖屏比例并重新生成，展示画幅自适应。
3. 点击“试听配音”。
4. 打开或关闭字幕。
5. 播放完整分镜预览。
6. 点击“导出字幕”，展示 SRT 文件。
7. 点击“录制并导出”，展示浏览器本地 Canvas 视频录制。

## 第五部分：在线增强与安全回退

口播：系统支持 OpenAI Compatible、DeepSeek 和 Qwen。在线服务为可选功能，不配置时不产生任何费用，也不影响核心流程。

操作：

1. 打开右上角设置。
2. 选择服务商并填写测试信息。
3. 展示失败时自动回退到离线引擎。
4. 强调 API Key 只保存在当前浏览器。

## 结束语

口播：本项目实现了离线可用、在线可选、可换背景、自动生成和成片导出的完整闭环，可作为 AI 应用与智能体类毕业设计进行展示和答辩。
