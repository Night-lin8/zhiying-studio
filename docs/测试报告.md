## 3. 异常与边界测试

| 编号 | 场景 | 结果 |
| --- | --- | --- |
| E-01 | 未上传素材直接导出 | 提示先上传主体素材，不抛出异常 |
| E-02 | 上传非图片文件 | 文件输入限制为图片格式，不处理其他文件 |
| E-03 | 在线接口返回非 JSON | 自动使用离线引擎，不中断页面 |
| E-04 | 浏览器不支持 MediaRecorder | 显示错误提示，不崩溃 |
| E-05 | 中文长文案 | 自动换行并限制预览字幕最多两行 |
| E-06 | 超大图片 | 加载时限制最长边为 1280 像素，避免内存过高 |
| E-07 | 关闭自动切镜 | 仅播放和导出当前镜头 |
| E-08 | 原文件保护 | 所有处理均在内存中进行，不修改用户原图 |

## 4. 回归验证

使用 Chrome Headless 加载本地页面，检查结果：

- JavaScript 无语法错误
- 离线引擎自动生成示例标题与分镜
- 点击“换一版”后标题与文案发生可见变化，并显示成功提示
- 预览或录制启动前等待首帧绘制完成，起始画面有完整内容
- DOM 中正确生成 6 张分镜卡片
- 内置背景图片正常加载
- 页面启动后无未捕获异常

## 5. 已知限制

- 离线抠像对复杂毛发边缘和非纯色背景依赖背景色取样，效果低于神经网络分割模型
- Web Speech API 的语音音色取决于操作系统安装的语音包
- WebM 导出依赖浏览器 MediaRecorder 支持，建议使用新版 Chrome 或 Edge
- 在线增强为可选功能，需要用户自行配置可用的 API 服务

## 6. 结论

核心功能、离线运行、异常回退和文件导出均已验证。系统满足毕业设计演示要求，可在不联网、不依赖付费服务的情况下完成完整业务流程。
