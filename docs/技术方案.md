# 技术方案：AI 品牌宣传视频智能体

## 1. 总体架构

系统采用纯前端浏览器架构，不依赖后端服务器和构建工具。项目包含静态页面、样式、JavaScript 业务逻辑和本地素材文件，双击 `index.html` 即可运行。

```text

  |
  v
创意简报表单
  |
  v
生成控制器
  |-- 在线模型可用 --> OpenAI Compatible / DeepSeek / Qwen API
  `-- 离线规则引擎 --> 模板、语气档案、创意方向、随机种子
  |
  v
宣传脚本模型
  |-- 标题、卖点、口播文案
  `-- 6 个分镜：场景、字幕、时长、背景、转场
  |
  +-------------------+-------------------+
  |                   |                   |
主体抠像             背景库              画幅适配
  |                   |                   |
  `-------- Canvas 合成 -------------+
                                      |
                                  成片预览
                                      |
                     +----------------+----------------+
                     |                |                |
                  配音试听         字幕导出        视频录制与导出
```

## 2. 技术选型

| 模块 | 技术 | 选择原因 |
| --- | --- | --- |
| 页面与样式 | HTML5 + CSS3 | 无需构建，直接运行 |
| 业务逻辑 | 原生 JavaScript ES2020 | 零依赖，离线可用 |
| 图像处理 | Canvas API + ImageData | 浏览器内置，可读取和修改像素 |
| 视频预览 | Canvas 2D + requestAnimationFrame | 支持动画和实时渲染 |
| 视频导出 | MediaRecorder + captureStream | 浏览器原生录制 Canvas 为 WebM |
| 本地配音 | Web Speech API | 系统语音引擎，无需联网 |
| 在线增强 | Fetch + OpenAI Compatible API | 支持多服务商，未配置时自动禁用 |
| 数据保存 | localStorage | 保存 API 配置和文本工作区，不保存用户素材 |

## 3. 核心模块

### 3.1 离线生成引擎

离线引擎根据行业、表达风格和创意方向选择模板档案，再根据输入文本计算稳定种子，生成以下内容：

- 品牌标题和宣传语
- 核心卖点
- 六段口播文案
- 六镜分镜脚本
- 每镜时长、背景和转场

同一输入会得到稳定结果，点击“换一版”时通过输入文本的哈希值增加变化因子。

### 3.2 在线生成增强

用户配置服务商、接口地址、模型和 API Key 后，系统向 OpenAI Compatible 接口发送结构化提示词。服务返回 JSON 后，系统校验并限制为 6 个分镜。请求失败、返回格式错误或当前离线时自动回退到离线引擎。

### 3.3 主体抠像

系统将上传图片缩放至最长边 1280 像素，再读取 RGBA 像素数据。支持：

- 背景色取样：点击画面背景获取目标颜色
- 绿幕抠像
- 蓝幕抠像
- 浅色背景

抠像流程：

1. 使用加权 RGB 距离计算像素与目标背景色的差异
2. 将差异映射为背景概率
3. 对绿幕和蓝幕像素执行溢色抑制
4. 使用可分离滑动窗口模糊对遮罩做边缘柔化
5. 将遮罩写入 Alpha 通道并输出透明 PNG
6. 检测 Alpha 内容包围盒，自动裁掉透明空白，合成时主体放大居中

### 3.4 Canvas 合成

系统根据所选画幅创建画布，将背景按覆盖模式绘制，再将透明主体等比缩放至画布中央。合成结果可直接应用到所有分镜预览。

### 3.5 成片预览与导出

预览画布按 16:9、9:16 或 1:1 创建。每个分镜按预设时长播放，绘制背景、主体、标题、镜头信息和字幕，并支持渐隐切换。录制时使用 Canvas `captureStream(30)` 与 `MediaRecorder` 输出 WebM。

## 4. 数据安全

- 用户上传图片只在浏览器内存和 Canvas 中处理
- 不上传原始图片到服务器
- 离线模式不发送任何网络请求
- API Key 使用 localStorage 保存在当前浏览器
- 部署脚本只复制项目文件，不删除目标目录内容

## 6. 性能设计

- 大图加载时限制最长边为 1280 像素
- 抠像遮罩使用 Float32Array 与可分离模糊，避免逐像素多层卷积
- 背景图片按需加载并缓存
- 预览渲染只重绘当前帧
- 视频录制使用 30fps 和 VP9/VP8 编码
- 优先使用 `createImageBitmap` 解码图片，并在不支持时回退到 FileReader
- 容差与柔化滑杆采用防抖调度，避免快速拖动时重复计算
- 内置背景在启动时并行预加载
- 创意输入与生成结果自动保存，刷新后可继续
- 在线请求设置 25 秒超时，失败自动回退离线引擎
