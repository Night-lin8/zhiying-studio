# 第 5 周・索引构建与评测使用说明

> 本文件为第 5 周新增交付物的使用指南，不修改原 README.md。
> 所有脚本为 Node.js ESM 模块，零外部依赖，可离线运行。

## 环境要求



* Node.js v18 及以上（开发环境为 v22.23.2）

* 无需安装任何 npm 包

## 1. 构建索引

将 `knowledge.data.js` 中已切分的 20 个知识块构建为 bigram TF-IDF 向量索引，存入 `data/index/index.json`。



```
node scripts/build_index.mjs
```

输出示例：



```
[索引] 构建完成：4 个文档，20 个知识块
[索引] 平台规范 4 个，违禁词 20 条
[索引] 耗时 0.02s，已存 data/index/index.json
[索引] 可重复执行：下次运行将自动清空旧索引后重建
```

特点：



* **可重复执行**：第二次运行前自动清空 `data/index/` 目录，不会出现重复块

* **元数据完整**：每个块存来源文档、章节、标签、块序号，供「依据」行引用

* **与浏览器端一致**：算法与 `knowledge.js` 完全相同，评测结果可复现

## 2. 单条检索

对一个问题执行真检索，返回 Top-3 片段（带出处与相似度），低于阈值 0.72 判定为无命中。



```
node scripts/retrieve.mjs "怎么提炼产品的核心卖点"
node scripts/retrieve.mjs "抖音竖屏分辨率是多少"
node scripts/retrieve.mjs "帮我写一篇英语作文"
```

输出包含：查询、阈值、命中与否、最高综合分（余弦相似度）、命中片段列表（出处、标签、内容摘要）。

## 3. 跑首轮评测

对 10 条预设问题（正常 6 / 边界 2 / 超纲 2）逐条跑检索，输出 `output/eval_round1.csv`。



```
node scripts/evaluate.mjs
```

评测列：序号、类别、测试问题、意图分支、命中段数、最高相似度、命中文档、命中章节、有依据、幻觉、判定、备注。
