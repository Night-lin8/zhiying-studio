# 智影工坊：AI 品牌宣传视频智能体

面向本科毕业设计的离线优先 AI 应用。系统在浏览器本地完成品牌输入、宣传文案与分镜生成、主体抠像、背景替换、字幕生成、配音预览和 WebM 成片导出；可选接入在线大模型服务。

## 启动

双击 `start.bat`（推荐，自动启动后端服务并打开浏览器），或双击 `start-server.bat`。

首次运行会自动安装 Node.js 依赖。需要 Node.js v18+（推荐 v20+）。

启动后访问 `http://127.0.0.1:8765`。

> 也可以直接双击 `index.html` 以纯本地模式运行，但此时无法使用账号登录和跨设备数据同步。

## 账号登录与数据同步

- **管理员账号**：`admin` / `123456`（首次启动自动创建）
- **注册**：在登录页切换到"注册"标签，填写用户名（2-20 位）和密码（至少 6 位）即可注册
- **登录**：注册成功后自动登录，也可使用已有账号登录
- **数据同步**：登录后，创意输入、生成内容、在线设置、知识助手对话会自动保存到服务端数据库；换一台电脑登录同一账号，数据自动恢复
- **退出登录**：点击右上角用户名，确认后退出（会清除本机该账号的缓存数据）
- **本地离线模式**：若后端服务未启动，登录页会显示"进入本地离线模式"按钮，可继续使用但数据仅保存在当前浏览器

### 跨电脑使用

后端服务默认监听 `0.0.0.0:8765`，同一局域网内其他电脑可通过 `http://<本机IP>:8765` 访问并登录同一账号。

若需在不同网络下使用，将整个项目部署到一台公网服务器（或云主机），运行 `npm install && node server.js` 即可。数据库文件位于 `data/app.db`，备份该文件即可迁移全部账号和数据。

### 环境变量（可选）

- `PORT`：服务端口，默认 8765
- `JWT_SECRET`：登录令牌密钥，生产环境务必修改

## 主要能力

- 离线规则引擎生成品牌标题、卖点、口播文案与 6 个分镜
- 可选 OpenAI Compatible、DeepSeek、Qwen 在线模型增强
- 背景色取样、绿幕、蓝幕和浅色背景四种抠像方式
- 容差与边缘柔化实时调整
- 抠像结果自动裁切到主体范围，合成时主体自动放大居中
- 内置四组品牌背景，支持自定义背景
- 16:9、9:16、1:1 三种成片比例
- Canvas 成片预览、自动切镜、字幕开关
- 浏览器本地配音试听
- 导出 Markdown 脚本、SRT 字幕、透明 PNG 和 WebM 视频
- 创意输入与生成内容自动保存到浏览器，刷新或下次打开可继续
- 在线增强支持独立开关，关闭时保留 API 配置
- 在线请求超时自动回退到离线引擎
- 图片解码与 Canvas 缩放采用高质量渲染

## 部署到 D 盘

双击 `install-to-d.bat`。该脚本仅向 `D:\code\AI-Graduation-Project` 添加或更新项目文件，不会删除 D 盘已有内容。

## 在线模式

点击右上角设置图标，选择服务商并填写接口地址、模型名称和 API Key。未配置时始终使用完全离线规则引擎。API Key 仅保存在当前浏览器的本地存储中。

设置面板中的“启用在线增强”开关可以直接暂停在线能力并保留已填写的 API 配置；再次打开开关即可恢复。点击顶部运行状态也可以进入设置。

## 第 5 周：索引构建与评测（RAG）

知识助手的检索引擎为 bigram TF-IDF 余弦 + 标签加权，Top-K=3、阈值 0.72，浏览器端运行时自动构建索引。以下命令行工具用于离线构建索引、单条检索验证和批量评测，需 Node.js v18+。

```bash
# 构建向量索引（可重复执行，自动清空旧索引）
node scripts/build_index.mjs

# 单条检索（带出处与相似度，低于 0.72 判定无命中）
node scripts/retrieve.mjs "怎么提炼产品的核心卖点"

# 跑首轮 10 条评测（正常 6 / 边界 2 / 超纲 2），输出 output/eval_round1.csv
node scripts/evaluate.mjs
```

- 索引产出：`data/index/index.json`（4 份文档、35 个知识块，含来源与章节元数据）
- 检索增强：同义词扩展（28 组口语→领域概念映射）+ Top-3 多片段综合回答
- 提示词版本：`prompts/system_v0.md`（第 4 周）→ `prompts/system_v1.md`（第 5 周，补回引用约束与兜底）
- 评测说明：`docs/02-【请替换姓名】-智影工坊AI品牌宣传视频智能体-检索与评测说明.docx`
